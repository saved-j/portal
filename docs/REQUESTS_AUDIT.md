## Архитектура и ядра

1. Два **полностью раздельных режима**: «Сеть порталов» = только mihomo (призрак-кор),
   «Простой портал» = **только Xray**, mihomo не запускается.
2. Xray — `libxray.so` в процессе приложения, tun-fd от VpnService.
3. Ядра пропатченные: mihomo `v1.19.34-portalmc.7`, Xray 26.11.9 (`676eaf66f8f0`).
4. Один владелец туннеля, поколения, быстрый переключатель (цель ≤1,5 с).
5. Плитка Quick Settings должна работать **при выгруженном приложении** (как в 0.01a).
6. Пинг только **через туннель**, не TCP-хендшейк.
7. Пинг **из самого ядра**, а не из пинг-теста: mihomo — URLTEST, Xray — `burstObservatory`;
   приложение только читает. Никаких наших фоновых процессов.
8. Две **независимые** сущности пинга для двух ядер — вид на экране один, внутри всё разное.
9. Пинг должен быть по **всем** серверам, одиночный — удержанием на строке.
10. Интервал автопинга: **30/60/90/120/180/240/300 с**, не короче 30; нажатие на молнию —
    переключатель (зелёная = включён), долгое нажатие — выбор интервала со сноской про батарею.
11. Для mihomo кнопка — **override**, если в подписке интервал 0 или отсутствует.
12. Битый конфиг не заменяет рабочий: сначала проверка, потом замена.
13. Обновление подписки — бесшовно, в фоне, без закрытия портала.
14. Подписка с одним ядром — работать в поддерживаемом режиме, два индикатора (серый/зелёный),
    серая кнопка «Да», сообщение «формат не поддерживается».
